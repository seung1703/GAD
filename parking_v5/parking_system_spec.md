## 1. 하드웨어 / 환경

- **라이다**: RPLidar A1M8, baudrate **115200** (256000 아님), 스캔 속도 5~10Hz
- **포트**: macOS, `/dev/cu.usbserial-0001` (`tty` 말고 `cu` 사용)
- **라이브러리**: `rplidar-roboticia` (`from rplidar import RPLidar`), `lidar.clean_input()` 연결 직후 호출
- **장착 위치**: 차량 **후방**, 차체 후단보다 약 100mm 뒤로 돌출. 차체가 전방 방향 시야 일부를 가림
- **구동계**: 유아용 토이카 개조. 아두이노 + 서보 드라이버(조향), DC 모터(구동). **엔코더/IMU 없음**
- **제어 통신**: 맥북(Python) → 아두이노 시리얼로 명령 전송 (조향각, 전/후진, 정지)
- **카메라**: 전방 장착, 차선 추종용 (기존 lane detection + P-control 스택 존재, Kp=4.0)

## 2. 대회 규격 (확정값)

- 도로 폭: 850mm, 차선 폭 50mm, 시작선 폭 100mm
- **주차 슬롯: 950 × 1500mm**, 4칸 일렬, 직각 주차
- 배치: `차-빈-차-빈` 또는 `빈-차-빈-차` 중 하나. **차 사이의 빈 칸**에 후진 주차
- 시작: IN 지점, 슬롯 구역에서 30cm 거리, **4개 시작점(10cm 간격 정사각형) 중 랜덤 1곳**, 슬롯을 정면으로 보고 출발
- 주차된 차량 = 동일한 토이카 (차폭 추정 500~600mm)
- **실측 갭(차체~차체) 예상: 약 1300~1400mm** (빈 슬롯 950 + 양옆 차량의 슬롯 내 여백)

## 3. 좌표계

- 라이다 원시 데이터: `(quality, angle_deg, distance_mm)`
- 변환: `x = d·sin(θ_rad)`, `y = d·cos(θ_rad)` — 단 **장착 각도 오프셋 상수 `MOUNT_OFFSET_DEG`를 angle에 더한 후** 변환
- 좌표계 정의: **후진 진행 방향 = +y** 가 되도록 오프셋을 잡는다 (라이다가 후방 장착이므로 후진 시 라이다가 슬롯을 정면으로 봄)
- 차체 가림 마스크 필수:
  ```python
  BLOCKED_SECTORS = [(lo, hi), ...]  # 차체가 가리는 각도 구간, 실측으로 결정
  MIN_VALID_DIST = 150               # mm, 이보다 가까운 점은 차체 반사로 간주하고 버림
  ```

## 4. 인지 파이프라인 (검증 완료된 알고리즘)

### 4.1 포인트 필터링
- `distance > 0`, `distance <= MAX_DISTANCE(3000)`, `quality >= MIN_QUALITY(10)`
- 차체 마스크(BLOCKED_SECTORS, MIN_VALID_DIST) 적용

### 4.2 클러스터링
- 각도순 정렬 후, **인접 포인트 간 xy 유클리드 거리**가 `CLUSTER_GAP_THRESH(200mm)` 초과 시 분리
- range 차이 기준이 아니라 xy 거리 기준 (비스듬한 표면에서 오분리 방지)
- `MIN_CLUSTER_POINTS = 1` (작은 파편도 클러스터로 유지 — 버리면 엉뚱한 원거리 연결 오탐 발생, 실측으로 확인된 버그)

### 4.3 코너 검출 (L-shape fitting)
- 클러스터를 두 구간으로 나눠 각 구간 PCA(전체최소제곱) 직선 피팅 잔차 합이 최소인 분할점 = 코너
- 코너 양쪽 벡터 사이 각도가 **50°~130°** 범위일 때만 유효 코너로 인정
- 포인트 6개 미만이거나 각도 조건 미달이면 → **최근접 점쌍(nearest pair) 폴백**

### 4.4 갭 감지
- 인접 클러스터 쌍 전체를 순회, 각 쌍의 코너(또는 폴백 점쌍) 간 거리 = 갭 폭
- `MAX_REASONABLE_GAP(2000mm)` 초과 쌍은 후보 제외 (원거리 오연결 방지 — 실측 버그 수정사항)
- 폭이 `SLOT_GAP_TARGET(1350mm) ± GAP_MARGIN(200mm)` 이면 유효 갭
- 유효 후보 여러 개면 자차와 가장 가까운 것 채택
- 유효 갭 없으면 정직하게 "없음" 반환 (억지 fallback 금지)

### 4.5 벽면 각도 추정
- 클러스터 포인트에 직선 피팅(np.polyfit 또는 PCA) → 기울기의 atan = 벽면 각도
- 후진 중 헤딩 정렬, 전진 스윙 회전량 측정에 사용

## 5. 미션 상태머신 (시간 하드코딩 금지 — 전부 조건 기반)

```
S0 CAMERA_STRAIGHT   카메라 차선/직진 유지로 전진
S1 GAP_TRIGGER       라이다: 유효 갭 확정 + 갭 중심이 (TRIGGER_GAP_ANGLE, TRIGGER_GAP_DIST)
                     도달 상태가 연속 3프레임 → 정지
S2 SWING_OUT         좌측 풀조향, 전진. 주차 차량 앞면 피팅 각도 ≥ 45° − SWING_STOP_EARLY
                     → 정지 (관성 오버슛 선보정)
S3 REVERSE_IN        우측 풀조향, 후진.
                     상시: 후방 REAR_EMERGENCY_DIST(120mm) 이내 물체 → 비상 정지
                     완료: 양옆 클러스터가 연속 3프레임 소멸 → 정지
                     (라이다가 차체보다 100mm 뒤 → 라이다 옆 점 소멸 = 차체 완전 진입)
                     회전 중 벽이 잠깐 안 보이는 프레임(None)은 조향 유지하고 계속 진행
S4 WAIT              3~5초 정지 대기
S5 EXIT_STRAIGHT     조향 중립, 직진 전진. 양옆 차 코너가 재출현 후
                     코너 y좌표 < −(LIDAR_TO_AXLE + margin) → 후미가 슬롯 밖 판정
S6 EXIT_SWING        좌측 풀조향 전진
S7 HANDOFF           카메라가 차선 유효 검출 → 차선 추종 모드로 복귀
```

## 6. 캘리브레이션 항목 (전부 1회 실측, 차량 고유값)

| 상수 | 의미 | 측정 방법 |
|---|---|---|
| `MOUNT_OFFSET_DEG` | 라이다 장착 각도 오프셋 | 알려진 방향 물체 놓고 화면 확인 |
| `BLOCKED_SECTORS` | 차체 가림 각도 구간 | 빈 공간에서 스캔, 항상 찍히는 근거리 점의 각도 범위 |
| `TRIGGER_GAP_ANGLE/DIST` | S1→S2 전환 시점의 갭 상대 위치 | 차를 이상적 스윙 시작 위치에 손으로 놓고 화면 값 읽기 |
| `SWING_STOP_EARLY` | S2 정지 명령 선행량 (관성 오버슛) | 실주행 오버슛 측정 |
| `LIDAR_TO_AXLE` | 라이다~후륜축 거리 | 자로 측정 |
| `SLOT_GAP_TARGET` | 실측 차체 간 갭 | 실제 배치에서 라이다로 측정 |
| 조향 서보 매핑 | PWM ↔ 실제 바퀴 각도 | 실측 |

## 7. 구현 요구사항

1. **스캔 수신 전용 스레드**: `iter_scans`는 버퍼가 밀리면 과거 데이터를 반환함.
   수신 스레드가 항상 최신 프레임만 공유 변수에 갱신하고, 제어 루프는 최신 프레임만 사용.
   (안 하면 판단이 1초 전 세상을 보게 됨 — 이동 중 제어에서 치명적)
2. **스캔 로거/리플레이어**: 모든 스캔을 pickle로 타임스탬프와 함께 기록하는 모드,
   기록 파일을 재생하며 알고리즘만 오프라인으로 돌리는 모드. 실차 없이 디버깅용
3. **캘리브레이션 모드**: 차를 임의 위치에 놓으면 갭 중심 각도/거리, 벽면 각도,
   클러스터 목록을 실시간 표시 (6번 표의 값들을 읽어내는 용도)
4. **시각화**: matplotlib 다크테마, 클러스터/코너(빨간 X)/갭(노란 점선+폭 라벨)/상태 표시.
   `blit=True` 시 patch 객체도 update 반환 튜플에 포함할 것
5. **아두이노 명령 인터페이스는 스텁으로**: `set_steering(deg)`, `motor_forward(speed)`,
   `motor_reverse(speed)`, `motor_stop()` 함수 시그니처만 정의, 내부는 시리얼 전송 TODO
6. **안전**: 후진 중 후방 비상거리 감시는 상태머신과 독립적으로 매 프레임 최우선 체크
7. 모든 튜닝 상수는 파일 상단 또는 별도 config에 모아둘 것

## 8. 알려진 함정 (이미 겪은 것들)

- A1M8에 baudrate 256000 쓰면 안 됨 → 115200
- macOS에서 `/dev/tty.*` 대신 `/dev/cu.*`
- "Descriptor length mismatch" → clean_input() + 전원 재연결로 해결됨
- 클러스터 최소 포인트를 3으로 잡으면 작은 물체가 버려져 멀리 있는 클러스터끼리
  엉뚱하게 연결됨 → MIN_CLUSTER_POINTS=1 + MAX_REASONABLE_GAP 상한으로 해결
- 2D 라이다는 물체의 보이는 면만 찍음 (차량이 짧은 선분/L자로 보이는 게 정상)
- 포인트 간격은 거리에 비례 (3m에서 ~25mm) → 원거리 코너 검출 신뢰도 낮음,
  주차 판단은 근거리(1~2m)에서만 신뢰
- 라이다 스캔 평면 높이가 주차 차량 차체를 지나가는지 장착 높이 확인 필수
