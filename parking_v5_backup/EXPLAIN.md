## 먼저: 차가 어떻게 "본다"는 걸까?

차 **뒤쪽에 라이다**라는 장치가 달려 있어요. 이건 **빙글빙글 돌면서 레이저로 사방의 거리를 재는 자**예요. 박쥐가 소리로 주변을 파악하는 것과 비슷해요.

라이다가 한 바퀴 돌면 **수백 개의 점**이 찍혀요. "이 방향 1.2m 앞에 뭔가 있다" 같은 점들이죠. 이 점들을 컴퓨터가 이렇게 처리해요:

1. **쓸데없는 점 버리기** — 너무 멀거나(3m 넘음), 차 자기 몸에 반사된 가까운 점(15cm 안쪽)은 버려요.
2. **점들을 뭉치로 묶기** — 서로 가까이 붙어있는 점들은 "같은 물체"예요. 이 뭉치 하나가 **주차된 차 한 대**죠.
3. **차의 모서리 찾기** — 라이다에서 차를 보면 'ㄱ'자(앞면+옆면)로 보여요. 그 꺾이는 지점이 **모서리**예요.
4. **빈 자리(갭) 찾기** — 옆에 있는 두 차의 모서리 사이 거리를 재요. 그게 **약 1350mm(우리 차가 들어갈 크기)**면 "여기가 주차할 자리다!" 하고 정해요.

> 핵심 규칙: 억지로 자리를 만들지 않아요. 딱 맞는 빈칸이 안 보이면 정직하게 "없음"이라고 해요.

## 상태(단계)별로 어떻게 움직이나?

주차는 **8단계**로 나뉘어요. 각 단계는 **시간으로 넘어가지 않고, "조건"이 맞아야** 다음으로 넘어가요. (예: "3초 뒤에" ❌ / "빈칸을 정확히 봤을 때" ⭕)

| 단계 | 하는 동작 | 다음으로 넘어가는 조건 |
|---|---|---|
| **S0 접근** | 카메라로 차선 따라 **앞으로 전진** | 빈칸을 **정확한 위치에서 3번 연속** 확인하면 → 멈춤 |
| **S2 앞으로 틀기** | 핸들 **왼쪽 끝**까지 꺾고 전진 | 옆 주차차량이 **비스듬히(약 45°) 보이면** → 멈춤 |
| **S3 꺾어 넣기** | 핸들 **오른쪽 끝**으로 꺾고 **후진** | 옆 차의 **벽이 내 후진 방향과 나란해지면**(정렬) → **바퀴를 중립으로 풀고** 넘어감 |
| **S3B 똑바로 넣기** | 핸들 **중앙** + 후진 | **양옆의 차가 안 보이게 되면**(= 내 차가 완전히 들어감) → 멈춤 |
| **S4 대기** | 그냥 **멈춰서 3~5초 기다림** | 시간 다 되면 → 출발 |
| **S5 똑바로 나가기** | 핸들 **중앙**, 앞으로 전진 | 양옆 차가 다시 보이고 **내 꽁무니가 자리 밖으로** 나오면 → 멈춤 |
| **S6 나가며 틀기** | 핸들 **왼쪽 끝**, 전진 | **카메라가 차선을 다시 찾으면** → |
| **S7 넘겨주기** | 주차 끝! **차선 주행 모드로 넘김** | (완료) |

쉽게 말하면:
- **들어갈 때**: 앞으로 조금 가서(S0) → 왼쪽으로 코 돌리고(S2) → 오른쪽으로 꺾어 뒤로 밀어넣다가, 자리와 나란해지면 바퀴 풀고 똑바로 쭉(S3→S3B).
- **나올 때**: 똑바로 앞으로(S5) → 왼쪽으로 코 돌려 빠져나옴(S6) → 다시 차선 주행(S7).

이건 우리가 사람이 후진 주차할 때 하는 동작이랑 똑같아요. "앞으로 살짝 → 핸들 꺾어서 뒤를 밀어넣다가 자리랑 나란해지면 핸들 풀고 쭉 후진."

### 왜 후진이 두 단계(S3 → S3B)로 나뉘어 있을까?

핸들을 **끝까지 꺾은 채로 계속 후진하면 차가 계속 빙글빙글 돌면서** 들어가요. 자리에 나란히 서는 게 아니라 비스듬하게 처박히죠. 그래서:
- **S3**: 일단 핸들 꺾어서 뒤를 밀어넣다가
- **자리랑 나란해지는 순간**(옆 차 벽이 내 후진 방향과 평행해 보이면): 핸들을 **중립으로 풀고**
- **S3B**: 그 상태로 똑바로 쭉 후진해서 완전히 들어감

"나란해졌다"는 걸 라이다로 옆 차 벽의 기울어진 정도를 계속 재서 판단해요.

## 제일 중요한 안전장치 🛑

후진(S3, S3B)할 때는 **뒤에 뭐가 있으면 무조건 즉시 멈춰요.** 이 검사는 상태머신과 **완전히 따로, 매 순간 1순위**로 돌아가요. 뒤 12cm 안에 뭔가 잡히면 다른 거 다 무시하고 브레이크.

> 재밌는 점: 원래 "15cm보다 가까운 점은 내 차 몸이니까 버려"라는 규칙이 있는데, 위험 감지 거리(12cm)가 그보다 가까워서 그냥 두면 **위험한 물체를 자기 몸으로 착각해 무시**해버려요. 그래서 뒤쪽만큼은 그 규칙을 빼고 봐요. (이게 만들면서 잡은 실제 함정이에요.)

## 왜 이렇게 "조건 기반"으로 만들었나?

바닥이 미끄럽거나 배터리가 약하면 **같은 시간 동안 가는 거리가 달라져요.** "2초 후진" 같은 방식은 어떤 날은 덜 들어가고 어떤 날은 박아요. 그래서 **"실제로 다 들어갔는지 라이다로 확인"**하는 방식이라, 상황이 조금 달라도 스스로 맞춰서 주차합니다.

## 지금 모든 조건이 라이다만 쓰는 건 아니에요

| 상태 | 동작에 쓰는 것 | **나가는 조건**에 쓰는 것 |
|---|---|---|
| S0 접근 | 🎥 카메라(차선 조향) + 전진 | 🛰 라이다 (갭이 트리거 위치 3프레임) |
| S2 앞틀기 | 조향만 | 🛰 라이다 (옆차 앞면각 ≥ 목표) |
| S3 꺾어넣기 | 조향만 + 후진 | 🛰 라이다 (옆차 벽면 정렬) |
| S3B 직진후진 | 조향만 + 후진 | 🛰 라이다 (양옆 클러스터 소멸) |
| S4 대기 | 정지 | ⏱ 타이머 (3~5초) |
| S5 나가기 | 조향만 + 전진 | 🛰 라이다 (코너 재출현 + y좌표) |
| S6 나가며틀기 | 조향만 + 전진 | 🎥 카메라 (차선 재검출) |
| S7 넘겨주기 | 정지 | 즉시 완료 |
| 후방 비상정지 | — | 🛰 라이다 (매 순간, S3·S3B) |

정리:
- **주차 기동의 핵심(S2~S5)은 전부 라이다** 조건입니다.
- **카메라가 필요한 곳은 2군데**: S0 접근 조향, S6→S7 차선 재검출.
- **S4 대기만 타이머** (스펙상 유일하게 시간 기반이 허용된 곳).
- 각 상태의 안전 타임아웃은 "폴백"이라, 라이다 조건이 정상이면 안 쓰입니다.

### ⚠️ 지금 카메라는 아직 진짜로 안 붙어있음

지금은 `NullCamera`(껍데기)라서:
- S0 접근 조향 → 그냥 **직진**(차선 안 봄)
- S6→S7 조건 → 카메라가 "못 찾음"만 반환하니 **타임아웃으로** 넘어감

즉 **라이다 구간(S2~S5)만 진짜로 완결**돼 있고, 카메라가 하는 두 부분은 스텁 상태입니다.

참고: 엔코더·IMU가 하드웨어에 아예 없어서 바퀴 회전량/기울기(오도메트리)는 전혀 안 씁니다. "얼마나 갔나"가 아니라 "라이다로 실제 상황을 봤나"로 판단하는 거예요.

## 그냥 직진하면 위험하지 않아?

**네, 위험합니다.** 지금 S0의 직진은 세 가지 이유로 안전하지 않아요.

### 1. 조향 피드백이 없어서 "직진 명령 ≠ 실제 직진"
바퀴를 중립으로 두라고 명령해도, 조향 중립 유격이나 바닥 기울기·바퀴 정렬 때문에 실제로는 **살짝 휘어서** 갑니다. 카메라가 "차선 보고 되돌려"를 안 하니 **한 번 틀어지면 스스로 못 고칩니다.**

### 2. ★가장 큰 문제★ — S0에 안전장치가 없음
지금 S0는 **갭을 트리거 위치에서 볼 때까지만** 전진합니다.
- **갭을 영영 못 보면** → 멈추는 조건이 없어서 **계속 앞으로 갑니다.**
- **전방 충돌 감지도 없습니다.** 라이다는 뒤(+y)를 보게 장착돼 있고 앞은 차체가 가려서, 앞에 뭐가 있어도 못 봐요.

최악의 경우 **계속 직진하다 슬롯을 지나치거나 벽에 박을 수 있습니다.**

### 3. 라이다가 앞을 잘 못 봄
후방 장착이라 전진 구간(S0)에서 라이다는 별 도움이 안 되고, 그래서 S0는 원래 카메라가 담당하도록 설계된 구간입니다.

### 해결 두 가지
- **A. 카메라 연결**: drive의 차선 스택을 S0 조향에 붙이면 차선 보고 똑바로 접근 (원래 의도).
- **B. S0 안전 페일세이프 추가**: 갭을 일정 거리/시간 안에 못 찾으면 안전 정지, 앞에 뭐가 있으면 멈추게.
