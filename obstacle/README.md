# 장애물 미션 — 초음파 감지 + 차선변경 주행

lane 프로젝트에서 완전 분리된 독립 폴더 (코드/모델/설정 모두 자체 사본).

## 동작 원리

```
KEEP(바깥 2차선) ──전방 초음파 < 45cm x3연속──▶ CHG_OUT(좌로 꺾기 0.6s)
    ▲                                              │
    │                                        CHG_ALIGN(카운터 0.45s)
    │                                              ▼
RET_ALIGN ◀── RET_OUT ◀──우측 초음파 통과확인── KEEP(안쪽 1차선)
```

- **차선변경 기동은 조건 기반 종료** (시간은 안전 타임아웃만):
  - 꺾기(OUT) 종료 = 비전 차선판정(lane_est)이 목표 차선으로 **플립** (점선을 실제로 넘은 증거)
  - 정렬(ALIGN) 종료 = **|헤딩| < align_heading_thresh** (차체가 차선과 평행해짐)
  - 각 단계 change_t_max(2.5s) 초과 시 강제 진행 → 속도·배터리 상태 변해도 동작 동일
- **현재 차선은 비전이 자동 판정** (수동 모드 전환 없음):
  좌우 경계를 클래스 무관 최근접으로 잡고, 잡힌 경계의 클래스로 판정 —
  왼쪽 경계=solid → 안쪽(1차선) / 오른쪽 경계=solid → 바깥(2차선).
  연속 4프레임(lane_switch_frames) 일치해야 전환 (점선 끊김 깜빡임 방지).
  → 기동이 어긋나도 상태가 실제 위치에 저절로 수렴 (자가 교정)
- **복귀 판정 (전방 2센서 구성): 시간 기반** — 안쪽 차선에서 `inner_hold_s`
  (기본 3초) 유지 후 복귀. 장애물 길이/주행 속도에 맞춰 튜닝하는 핵심 값.
  (우측 센서를 나중에 추가하면 config `us_right_ids`에 인덱스만 넣으면
  "봤다가 사라짐" 통과확인 로직이 자동으로 우선 적용됨)

## 준비 (실차 전 필수)

1. **펌웨어 업로드**: `../firmware/firmware.ino` (주행·장애물 공용 통합 펌웨어)
   초음파: 전방 2개 — 0번(TRIG 23, ECHO 22), 1번(TRIG 25, ECHO 24)
   ★ 실제 배선 핀이 다르면 `US_TRIG`/`US_ECHO` 배열 수정 ★
   ※ 초음파는 펌웨어 기본 OFF. 장애물 미션 실행 시 serial_driver가 자동으로
     ON 명령(0x40 0x01)을 보내 켠다. 주행 미션에선 꺼진 채로 둔다.
2. **확인**: 시리얼 모니터(115200)로 볼 땐 파이썬을 끄고 확인 — 파이썬이 안 켜면
   초음파도 안 켜지므로 "U0/U1" 라인이 안 보인다. pot "P:xxx"는 항상 나온다.
   (모니터에서 초음파 강제 확인은 어려우니 파이썬 로그의 us 값으로 확인 권장)
3. calib.json은 lane 프로젝트의 튜닝값을 복사해옴 — 카메라 각도 같으면 그대로 OK

## 실행

```
python main_obstacle.py --dry        # 책상 테스트 (시리얼 없이 화면만)
python main_obstacle.py --steeronly  # 조향 전용 테스트: 뒷바퀴 정지 상태로
                                     # 초음파→차선변경 기동이 바퀴 조향으로만 재생
python main_obstacle.py              # 실차
```

키: `s`출발 `x`정지 | **`o`=수동 차선변경, `p`=수동 복귀** (초음파 없이 기동 튜닝용)
`t`튠모드 `w`저장 `d`디버그 `q`종료 | ESC 비상정지

## 현장 튜닝 순서

1. `--dry` + `o`/`p` 키로 화면에서 상태 전환 확인
2. 실차, 장애물 없이: `o` 눌러 **차선변경 기동 튜닝** — Settings의
   `ChgSteer`(꺾는 양) / `T_out`(꺾는 시간) / `T_align`(정렬 시간)을
   "안쪽 차선 중앙에 대략 도착"할 때까지 조정 (정밀할 필요 없음 —
   도착 후 비전이 이어받아 중앙으로 수렴함)
3. `p`로 복귀 기동도 동일하게
4. 실제 장애물 놓고: `ObsTrig cm`(감지 거리) 조정 — 너무 크면 오발동,
   너무 작으면 못 피함. 속도(PWM)에 맞춰 조정
5. 안쪽 주행 중 복귀가 너무 이르면(장애물 옆구리를 치면) `inner_hold_s` ↑,
   너무 늦으면(다음 코너까지 안쪽에 있으면) ↓ — calib.json에서 조정

## 주의

- 시리얼 포트는 한 프로세스만 (아두이노 IDE 모니터 닫기)
- 상태머신은 RUN 중에만 동작 (STOP 상태에선 오발동 방지 위해 동결)
- 차선 로스트 30프레임 → 즉시 정지 (기동 중에는 로스트 카운트 정지)
